# UI Fidelity Notes

## Goals
- Closely resemble Microsoft 365.
- Maximize learning transfer to the live application.

## Requirements
- Accurate ribbon density
- Proper group spacing
- Small dropdown arrows
- Realistic styles gallery
- Office Search box
- Quick Access Toolbar
- ScreenTips

## Lessons Learned

### Prototype 2
Looked less authentic because controls were arranged in uniform grids.

### Better Approach
Use a mix of:
- Large vertical controls
- Compact horizontal controls
- Stacked controls

This more closely matches the actual Office ribbon.
