IS101 — Introduction to Computing

Learning Objectives

What you'll be able to do by the end of each unit. Objectives are written with the action verb bolded, ordered from foundational to higher-order skills within each unit.

Unit 1 — Artificial Intelligence

It is Real!

  • Explain how LLMs predict text word-by-word, producing non-deterministic, sometimes confidently wrong answers.
  • Distinguish RAG-based tools (NotebookLM) from general-purpose LLMs (ChatGPT) by how each handles sources and hallucination risk.
  • Verify an AI-generated claim by tracing its citation back to the source.
  • Apply an ethical framework to judge when AI use is appropriate.
  • Use NotebookLM to research and study from a set of grounded sources.
Unit 2 — Microsoft Word 365

Word Processing

One objective per skill domain, plus a capstone for the applied project.
  • Apply document-level settings — margins, style sets, headers/footers, watermarks, and properties — to prepare a professional document. (D1 — Manage Documents)
  • Organize text and paragraphs into a structured document using styles, spacing, and section/page/column breaks. (D2 — Format Text, Paragraphs & Sections)
  • Design tables and lists that organize and present information clearly. (D3 — Manage Tables and Lists)
  • Integrate reference tools — a table of contents, footnotes, and endnotes — to support navigation and citation. (D4 — References)
  • Compose a visual layout that combines pictures, shapes, and text boxes with proper wrapping and alt text. (D5 — Graphic Elements)
  • Evaluate feedback on a document and respond to it using comments and Track Changes. (D6 — Collaboration)
  • Produce a complete, professional business document that combines all six domains into one deliverable. (Capstone — Word Projects)
Unit 3 — Microsoft Excel 365

Spreadsheets

One objective per skill domain, plus a capstone for the applied project.
  • Organize worksheets and workbooks — layout, navigation, and page setup — for a usable spreadsheet. (E1 — Manage Worksheets and Workbooks)
  • Apply formatting and range-management techniques to prepare spreadsheet data for use. (E2 — Manage Data Cells and Ranges)
  • Structure raw data into Excel Tables, then filter and sort it to support analysis. (E3 — Manage Tables and Table Data)
  • Construct formulas and functions — including logical, lookup, and text functions — to solve calculation problems. (E4 — Formulas and Functions)
  • Create charts that visually communicate spreadsheet data. (E5 — Manage Charts)
  • Produce a complete, functional workbook that applies worksheet management, data formatting, tables, formulas, and charts to a real business scenario. (Capstone — Excel Projects)
Unit 4 — Presentations

AI-Powered Tools and Presentation Software

This unit is still growing — these objectives reflect the two AI-focused assignments currently available.
  • Generate presentation content from a single prompt using multiple AI tools.
  • Compare the outputs different AI tools produce from the same prompt.
  • Evaluate how completely and accurately an AI tool completes a real, structured project against a known solution.
  • Critique AI-generated work in writing, weighing its strengths, errors, and trustworthiness.
