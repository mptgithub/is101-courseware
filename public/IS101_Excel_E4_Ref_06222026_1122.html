Relative, absolute, and mixed references
▾

Why this matters

Absolute ($) references lock a cell so it doesn't shift when a formula is copied.

Where to find it

$ toggling (F4)

How to do it

  1. Click in the formula on a reference.
  2. Press F4 to cycle A1 → $A$1 → A$1 → $A1.
  3. Copy the formula to confirm the locked part stays.

How you'll know it worked

Copied formulas keep the $-locked reference fixed.

Structured references in formulas
▾

Why this matters

Structured references use table/column names instead of cell addresses, so formulas stay readable.

Where to find it

Table[Column] syntax

How to do it

  1. Inside or beside a Table, start a formula.
  2. Reference a column as TableName[Column].
  3. Press Enter.

How you'll know it worked

The formula shows the column name in brackets and calculates correctly.
