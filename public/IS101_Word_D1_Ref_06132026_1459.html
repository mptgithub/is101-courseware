Set Page Margins
Layout tab → Page Setup group
▾
Why This Matters
Professional documents use consistent margins. Most business reports require 1-inch margins on all sides — the default in Word.
Where to Find It
Layout tab → Page Setup group → Margins
How to Do It
  • 1Click the Layout tab on the ribbon.
  • 2In the Page Setup group, click Margins.
  • 3Choose Normal (1" all sides) from the dropdown, or click Custom Margins to enter exact values.
How You'll Know It Worked
The ruler at the top of the document shows the margin boundaries. File → Print preview shows the correct white space around the text.

Insert Header
Insert tab → Header & Footer group
▾
Why This Matters
Headers appear at the top of every page. Business reports commonly show the company name on the left and the date on the right.
Where to Find It
Insert tab → Header & Footer group → Header
How to Do It
  • 1Click the Insert tab.
  • 2Click Header in the Header & Footer group.
  • 3Choose a style from the dropdown, or click Edit Header to type directly.
  • 4Press Tab to move between left, center, and right sections of the header.
How You'll Know It Worked
A dashed border appears at the top of the document. Your header text is visible on every page. Double-click the body text to exit header editing.

Modify Document Properties
File tab → Info
▾
Why This Matters
Document properties (Title, Author, Company) are embedded in the file and appear in Windows Explorer and file management systems. They help identify and organize documents.
Where to Find It
File tab → Info → Properties panel
How to Do It
  • 1Click the File tab to open the backstage view.
  • 2Click Info in the left menu.
  • 3On the right side, find the Properties panel.
  • 4Click each field (Title, Author, Company) to type your information.
  • 5Press Esc or click the back arrow to return to the document.
How You'll Know It Worked
Right-click the saved file in Windows Explorer → Properties → Details tab to confirm the fields are saved.

Remove Hidden Properties
File tab → Info
▾
Why This Matters
Word documents store hidden metadata — edit history, author names, comments — that should be removed before sharing externally for privacy and professionalism.
Where to Find It
File tab → Info → Check for Issues → Inspect Document
How to Do It
  • 1Click the File tab → Info.
  • 2Click Check for Issues → Inspect Document.
  • 3Click Inspect to run the check.
  • 4Click Remove All next to Document Properties and Personal Information.
How You'll Know It Worked
Re-run the inspection. The Document Properties section should now show a green checkmark.

Find Text
Home tab → Editing group
▾
Why This Matters
The Navigation Pane's Find feature locates every instance of a word or phrase instantly — essential before doing a Find & Replace.
Where to Find It
Home tab → Editing group → Find (or Ctrl+F)
How to Do It
  • 1Press Ctrl+F to open the Navigation Pane, or click the Home tab → Find.
  • 2Type the word or phrase in the search box.
  • 3Word highlights all matches and shows a count. Click the arrows to jump between them.
How You'll Know It Worked
All instances are highlighted in yellow in the document. The Navigation Pane shows the total count found.
