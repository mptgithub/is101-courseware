Create an Excel Table
Insert tab → Tables group
▾
Why This Matters
Convert the event data range A1:G50 into a structured Excel Table.
Where to Find It
Insert tab → Tables group → Table (or Ctrl+T)
How to Do It
  • 1Select any cell in the data range.
  • 2Insert tab → Tables → Table (or Ctrl+T).
  • 3Confirm range A1:G50 → check My table has headers → OK.
How You'll Know It Worked
Data becomes an Excel Table with filter dropdowns, banded rows, and a Table Design tab.

Insert and Configure Total Row
Table Design tab → Table Style Options
▾
Why This Matters
Add a Total Row and configure aggregation functions per column.
Where to Find It
Table Design tab → Table Style Options → Total Row
How to Do It
  • 1Click inside the table.
  • 2Table Design tab → Table Style Options → check Total Row.
  • 3Click a cell in the Total row → dropdown appears.
  • 4Choose Sum for Revenue, Count for Event Name, etc.
How You'll Know It Worked
A Total row appears at the bottom with aggregate values. Each cell has a function dropdown.

Filter and Sort Table Data
Table header dropdown arrows
▾
Why This Matters
Filter to show only Corporate events, then sort by Date ascending.
Where to Find It
Table header dropdown arrows
How to Do It
  • 1Click the Category dropdown → uncheck Select All → check Corporate → OK.
  • 2Click the Date dropdown → Sort Oldest to Newest.
  • 3To clear: click the funnel icon in Category → Clear Filter.
How You'll Know It Worked
Only Corporate rows are visible, sorted by date. A funnel icon shows in the Category header.

▾

Remove Duplicate Records
Table Design tab → Tools group
▾
Why This Matters
Find and remove all duplicate rows caused by a data import error.
Where to Find It
Table Design tab → Tools group → Remove Duplicates
How to Do It
  • 1Click inside the table.
  • 2Table Design tab → Tools → Remove Duplicates.
  • 3Select columns to check → OK.
  • 4Excel reports how many duplicates were removed.
How You'll Know It Worked
A dialog confirms duplicates removed. The table now contains only unique records.
