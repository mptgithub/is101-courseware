Create a Table
Insert tab → Tables group
▾
Why This Matters
Convert the quarterly revenue plain text data into a professional 4-column table.
Where to Find It
Insert tab → Tables group → Table
How to Do It
  • 1Click where you want the table.
  • 2Insert tab → Tables group → Table.
  • 3Drag to select 4 columns and the right number of rows.
  • 4Type data into each cell. Press Tab to move between cells.
How You'll Know It Worked
A clean bordered table appears. Data is organized in columns: Quarter, Revenue, Expenses, Net Profit.
