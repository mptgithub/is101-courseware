Add & Rename a Worksheet
Right-click sheet tab → Insert / Rename
▾
Why This Matters
Add a new worksheet to the workbook and rename it "Q4 Data".
Where to Find It
Right-click sheet tab → Insert / Rename
How to Do It
  • 1Right-click any sheet tab at the bottom.
  • 2Choose Insert → Worksheet → OK.
  • 3Double-click the new tab to rename it.
  • 4Type Q4 Data and press Enter.
How You'll Know It Worked
A new sheet tab labeled "Q4 Data" appears at the bottom of the workbook.

Configure Rows and Columns
Right-click row/column header
▾
Why This Matters
Set data row heights to 20 pixels and auto-fit column A to its content width.
Where to Find It
Right-click row/column header
How to Do It
  • 1Select the data rows.
  • 2Right-click → Row Height → type 20 → OK.
  • 3For column A: right-click column A header → AutoFit Column Width.
How You'll Know It Worked
Selected rows are uniform height. Column A is wide enough to show all content.
