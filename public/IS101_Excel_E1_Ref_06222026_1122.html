Import data from text files
▾

Why this matters

Real-world data often arrives as CSV exports from other systems. Importing cleanly keeps data types intact instead of pasting text.

Where to find it

Data → Get Data → From Text/CSV

How to do it

  1. Go to the sheet with the empty target range.
  2. Data → Get Data → From Text/CSV.
  3. Browse to the provided .csv and click Import.
  4. Confirm the delimiter in the preview and click Load.

How you'll know it worked

The previously-empty cells contain the imported rows, numbers right-aligned.

Import data from online sources
▾

Why this matters

Excel can pull data straight from a web page and refresh it on demand instead of manual re-entry.

Where to find it

Data → Get Data → From Other Sources → From Web

How to do it

  1. Data → Get Data → From Other Sources → From Web.
  2. Paste the URL and click OK.
  3. Pick the table in the Navigator and click Load.

How you'll know it worked

A live query table appears under Queries & Connections.

Insert and remove hyperlinks
▾

Where to find it

Insert → Link (Ctrl+K)

How to do it

  1. Select the cell.
