Insert Table of Contents
References tab → Table of Contents group
▾
Why This Matters
Insert an automatic Table of Contents after the title page based on heading styles.
Where to Find It
References tab → Table of Contents group → Table of Contents
How to Do It
  • 1Click after the title page.
  • 2References tab → Table of Contents → Table of Contents.
  • 3Choose Automatic Table 1 or Automatic Table 2.
How You'll Know It Worked
A formatted TOC appears with clickable entries and page numbers. Ctrl+click any entry to jump there.

Customize Table of Contents
References tab → Table of Contents
▾
Why This Matters
Customize the TOC to show only Heading 1 and Heading 2 with dotted leaders.
Where to Find It
References tab → Table of Contents → Custom Table of Contents
How to Do It
  • 1References tab → Table of Contents → Custom Table of Contents.
  • 2Set Show levels: 2.
  • 3Confirm Tab leader is dots (......)
  • 4Click OK → Yes to replace the existing TOC.
How You'll Know It Worked
The TOC shows only two heading levels with dotted leaders connecting entries to page numbers.

Update Table of Contents
References tab → Table of Contents group
▾
Why This Matters
Update the TOC after editing so page numbers and headings are current.
Where to Find It
References tab → Table of Contents group → Update Table
How to Do It
  • 1Click anywhere inside the TOC.
  • 2References tab → Table of Contents group → Update Table.
  • 3Choose Update page numbers only or Update entire table.
  • 4Click OK.
How You'll Know It Worked
The TOC refreshes with current page numbers and any changed headings.

Insert Footnote
References tab → Footnotes group
▾
Why This Matters
Insert a footnote on the revenue figure citing the data source.
Where to Find It
References tab → Footnotes group → Insert Footnote
How to Do It
  • 1Click immediately after the revenue figure.
  • 2References tab → Footnotes group → Insert Footnote.
  • 3A superscript number appears; the cursor moves to the page bottom.
  • 4Type: Source: DSC Financial Records 2026.
How You'll Know It Worked
A superscript number appears after the figure. The footnote text appears at the bottom of that page.

Insert Caption
References tab → Captions group
▾
Why This Matters
Add a figure caption below the quarterly revenue chart.
Where to Find It
References tab → Captions group → Insert Caption
How to Do It
  • 1Click the chart or image to select it.
  • 2References tab → Captions group → Insert Caption.
  • 3Label: Figure, type: Quarterly Revenue 2026.
  • 4Position: Below selected item → OK.
How You'll Know It Worked
"Figure 1: Quarterly Revenue 2026" appears below the chart. Word auto-numbers all figures.
