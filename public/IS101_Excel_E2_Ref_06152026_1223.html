Fill Cells Using AutoFill
Fill handle (bottom-right corner of selected cells)
▾
Why This Matters
The month column has only January and February. Use AutoFill to complete through December.
Where to Find It
Fill handle (bottom-right corner of selected cells)
How to Do It
  • 1Select the cells containing January and February.
  • 2Hover over the bottom-right corner until you see the fill handle (+).
  • 3Drag down to December.
  • 4Release — Excel completes the series.
How You'll Know It Worked
Cells fill with March through December. Excel recognizes the month series pattern.

Insert and Delete Columns/Rows
Right-click column/row header
▾
Why This Matters
Insert a new "Department" column between B and C, and delete the duplicate row 14.
Where to Find It
Right-click column/row header
How to Do It
  • 1Right-click column C header → Insert. New column inserts to the left.
  • 2Type header: Department.
  • 3Right-click row 14 number → Delete.
How You'll Know It Worked
A Department column appears between B and C. Row 14 is gone and rows below shift up.

▾
Why This Matters
Format the salary column as Currency and the date column as MM/DD/YYYY.
Where to Find It

  • 1Select salary cells → Home → Number → $ → Currency.

Salaries show with $ and 2 decimal places. Dates display in MM/DD/YYYY format.

Name Cell Ranges
Name Box (top-left) or Formulas tab → Define Name
▾
Why This Matters
Define the name "Salaries" for the range B2:B25 for use in formulas.
Where to Find It
Name Box (top-left) or Formulas tab → Define Name
How to Do It
  • 1Select B2:B25.
  • 2Click the Name Box → type Salaries → press Enter.
  • 3Or: Formulas tab → Defined Names → Define Name → type Salaries → OK.
How You'll Know It Worked
The Name Box shows "Salaries" when that range is selected. Use =SUM(Salaries) in formulas.
