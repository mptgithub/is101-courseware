Create a Chart
Insert tab → Charts group
▾
Why This Matters
Create a Column chart showing monthly headcount to visualize staffing trends.
Where to Find It
Insert tab → Charts group
How to Do It
  • 1Select the data range (include headers).
  • 2Insert tab → Charts → Insert Column or Bar Chart.
  • 3Choose Clustered Column from 2-D Column options.
How You'll Know It Worked
A column chart appears. Chart Design and Format tabs appear on the ribbon.

▾
Why This Matters
Add data labels, a trendline, and move the legend to the bottom.
Where to Find It
Chart Design tab → Add Chart Element (or + icon)
How to Do It
  • 1Chart Design tab → Add Chart Element → Data Labels → Above.
  • 2Add Chart Element → Trendline → Linear.
  • 3Add Chart Element → Legend → Bottom.
How You'll Know It Worked
Data labels show exact values above each point. A trendline runs through the data. Legend is at the bottom.

The Alt Text pane shows the description. Screen readers can now describe the chart.
