Paste using special paste options
▾

Why this matters

Paste Special lets you paste only values, formats, or formulas — not everything at once.

Where to find it

Home → Paste → Paste Special

How to do it

  1. Copy the source.
  2. Home → Paste dropdown → Paste Special.
  3. Choose Values, Formats, or Transpose, then OK.

How you'll know it worked

Only the chosen aspect (e.g. values) is pasted.

Fill cells by using AutoFill
▾

Why this matters

AutoFill extends a series (months, numbers, dates) without retyping each value.

Where to find it

Fill handle drag / Home → Fill

How to do it

  1. Type the first value(s) to establish the pattern.
  2. Select them and drag the fill handle (bottom-right corner) across the blank cells.

How you'll know it worked

The blank cells fill with the continued series (e.g. Jan, Feb, Mar…).

Generate data: RANDBETWEEN(), SEQUENCE()
▾

Why this matters

These functions generate test data or numbered sequences automatically.

Where to find it

Formulas → Math & Trig

How to do it

  1. Click the target cell.
  2. Type =RANDBETWEEN(1,100) for a random number, or =SEQUENCE(10) for 1–10.
  3. Press Enter.

How you'll know it worked

The cell(s) populate with generated values.
