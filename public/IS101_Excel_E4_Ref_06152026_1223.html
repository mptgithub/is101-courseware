SUM Function
Formulas tab → Function Library
▾
Why This Matters
Calculate total January sales by summing all values in the sales column.
Where to Find It
Formulas tab → Function Library → AutoSum → SUM (or Alt+=)
How to Do It
  • 1Click the result cell.
  • 2Type =SUM( → select the range → ) → Enter.
  • 3Or press Alt+= to AutoSum the column above.
How You'll Know It Worked
Cell displays the sum. Formula bar shows =SUM(B2:B31) or similar.

IFERROR Function
Formulas tab → Function Library
▾
Why This Matters
Wrap the VLOOKUP in IFERROR so unmatched codes show "Not Found" instead of #N/A.
Where to Find It
Formulas tab → Function Library → Logical → IFERROR
How to Do It
  • 1Edit the VLOOKUP formula to:
  • 2=IFERROR(VLOOKUP(A2,PriceTable,2,FALSE),"Not Found")
  • 3Press Enter. Copy down.
How You'll Know It Worked
Successful lookups show the price. Unmatched codes show "Not Found" instead of #N/A.
