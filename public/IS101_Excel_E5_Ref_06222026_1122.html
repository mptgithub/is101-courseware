Create charts
▾

Why this matters

Charts turn rows of numbers into a visual that reveals trends instantly.

Where to find it

Insert → Charts

How to do it

  1. Select the data including headers.
  2. Insert → Charts → pick a type (Column, Line, Pie).
  3. The chart appears on the sheet.

How you'll know it worked

A chart embeds on the worksheet showing your data.

Create chart sheets
▾

Why this matters

Moving a chart to its own sheet gives it a full-page, dedicated view.

Where to find it

Chart Design → Move Chart → New sheet

How to do it

  1. Click the chart.
  2. Chart Design → Move Chart.
  3. Choose New sheet, OK.

How you'll know it worked

The chart moves to its own dedicated chart sheet tab.

Learn more: LinkedIn Learning Perplexity Microsoft Support
Add data series to charts
▾

Why this matters

Adding a series plots an additional set of values on the same chart.

Where to find it

Chart Design → Select Data → Add

How to do it

  1. Click the chart.
  2. Chart Design → Select Data.
  3. Click Add, set the series name and values, OK.

How you'll know it worked

The chart shows the additional series.

Switch between rows and columns in source data
▾

Why this matters

Switching row/column flips which data is the category axis vs the series.

Where to find it

Chart Design → Switch Row/Column

How to do it

  1. Click the chart.
  2. Chart Design → Switch Row/Column.

How you'll know it worked

The chart redraws with series and categories swapped.

▾

Elements like data labels, titles, and trendlines make a chart self-explanatory.

Add alternative text to charts
▾

Why this matters

Alt text describes a chart for screen readers — required for accessibility.

Where to find it

Right-click chart → Edit Alt Text

How to do it

  1. Right-click the chart → Edit Alt Text.
  2. Type a concise description.
  3. Close the pane.

How you'll know it worked

The Alt Text pane shows your description saved to the chart.
